# Cyber Type 2.0

Cyber Type 2.0 is a web-based typing game built with HTML, CSS, and JavaScript.

## Live Demo

Play the game online:
https://oliviasophia67.github.io/Cyber-Type-2.0/

## Features

- Tracks your typing speed (WPM) and accuracy in real time
- Clean and simple user interface
- Built with vanilla HTML, CSS, and JavaScript

## Project Files

- index.html - Page structure
- style.css - Page styling
- script.js - Game logic

## How to Run Locally

1. Download or clone this repository.
2. Open index.html in your web browser.
